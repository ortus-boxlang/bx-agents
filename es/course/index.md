# Introducción a BxAgents

Veinte lecciones, de principio a fin: instala la CLI, crea el andamiaje de un proyecto,
entiende `Agent.bx`, conecta tools, skills y subagentes, expón tu agente por HTTP y a
plataformas de chat, publica la UI web generada, programa trabajo en segundo plano, pruébalo de
verdad, y empaquétalo y despliégalo. Cada lección enlaza de vuelta a la referencia completa de
[Convenciones](../conventions/agent-bx.md) para la inmersión profunda - este curso es el camino
guiado a través de ella.

!!! info
    Cada lección guarda tu progreso en este navegador (sin necesidad de cuenta) - visita una
    lección y queda marcada como leída, y **Continuar donde lo dejaste**, más abajo, retoma
    justo donde paraste.

::: course id="intro-to-bxagents" :::

## Para quién es esto

Para cualquiera que quiera construir un agente de IA sin cablear a mano la superficie de API de
un framework - describes un agente con **archivos y carpetas**, y `bxAgents build` ensambla con
ello una aplicación [ColdBox](https://www.coldbox.org) real y ejecutable. No se presupone
experiencia previa con BoxLang ni ColdBox, aunque ayuda.

## Qué habrás construido al llegar a la Lección 20

Un agente con sus propias tools y una skill empaquetada, accesible desde la CLI, desde una UI
de chat en el navegador y desde una API HTTP, con una suite de pruebas que se ejecuta sin
ninguna clave de API, y un `.bxa` empaquetado listo para desplegar.

¿Listo? Empieza con la [Lección 1: Bienvenido a BxAgents](01-welcome.md).
