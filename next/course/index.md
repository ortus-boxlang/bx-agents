# Introduction to BxAgents

Twenty lessons, start to finish: install the CLI, scaffold a project, understand
`Agent.bx`, wire up tools, skills and subagents, expose your agent over HTTP and to
chat platforms, ship the generated web UI, schedule background work, test it for real,
and package + deploy it. Every lesson links back to the full [Conventions](../conventions/agent-bx.md)
reference for the deep dive - this course is the guided path through it.

!!! info
    Each lesson tracks your progress in this browser (no account needed) - visit a
    lesson and it's marked read, and **Continue where you left off** below picks up
    right where you stopped.

::: course id="intro-to-bxagents" :::

## Who this is for

Anyone who wants to build an AI agent without hand-wiring a framework's API surface -
you describe an agent with **files and folders**, and `bxAgents build` assembles a real,
runnable [ColdBox](https://coldbox.ortusbooks.com) application out of it. No prior
BoxLang or ColdBox experience is assumed, though it helps.

## What you'll have built by Lesson 20

An agent with its own tools and a packaged skill, reachable from the CLI, a browser chat
UI, and an HTTP API, with a test suite that runs with no API key, and a packaged `.bxa`
ready to deploy.

Ready? Start with [Lesson 1: Welcome to BxAgents](01-welcome.md).
