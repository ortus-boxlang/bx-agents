# Introducción a BxAgents

Veintinueve lecciones, un agente. Instalas la CLI, arrancas un modelo guionizado que no necesita cuenta ni clave, y
construyes *Acme support* lección a lección: sus instrucciones, una tool, una skill, subagentes y perfiles, y después la
app web, las aprobaciones, la memoria, las rutinas, el control de acceso, una bóveda de secretos, los ajustes por persona,
los logs y las copias de seguridad, las pruebas y un `.bxa` empaquetado. Cada lección enlaza de vuelta a la referencia
completa de [Convenciones](../conventions/agent-yaml.md) para la inmersión profunda - este curso es el camino guiado a
través de ella.

!!! info
    Cada lección guarda tu progreso en este navegador (sin necesidad de cuenta) - visita una
    lección y queda marcada como leída, y **Continuar donde lo dejaste**, más abajo, retoma
    justo donde paraste.

::: course id="intro-to-bxagents" :::

## Para quién es esto

Para cualquiera que quiera construir un agente de IA sin cablear a mano la superficie de API de
un framework - describes un agente con **archivos y carpetas**, y `bxAgents build` ensambla con
ello una aplicación [ColdBox](https://www.coldbox.org) real y ejecutable. No se presupone
experiencia previa con BoxLang ni ColdBox, aunque ayuda, ni hace falta una clave de API.

## Qué habrás construido al llegar a la última lección

Acme support: un agente con su propia tool, una skill y dos subagentes, accesible desde un chat de terminal, una app web y
una API HTTP, con una rutina que guarda informes, aprobaciones donde una persona debe decir que sí, notas, cuentas y tokens,
una bóveda, pruebas que se ejecutan sin clave, una copia de seguridad y un `.bxa` empaquetado listo para desplegar.
