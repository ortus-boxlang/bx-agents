    Quick start

    From nothing to a chat in four commands.

    Install the module, scaffold an agent, build it, and talk to it. Nothing else to configure.

    1Installinstall-bx-module bx-agents
    2ScaffoldbxAgents new my-agent \ --model=openai/gpt-5
    3Buildcd my-agent bxAgents build
    4Talk to itbxAgents chat # or serve over HTTP bxAgents serve --port=8080
    Then open http://127.0.0.1:8080. Bound to localhost only.
    Watch it work

    Real runs, recorded.

    Every clip is a real session against a real served agent. The model is the mock provider the examples ship with, so each answer is "Mock response" and no model was called.

    From nothing to a running agent

    Four files, one running agent

    You write the agent. The folders do the wiring.

    This is the whole simple-agent example from the repo: a YAML file, a prompt, one tool. Add a folder when you need it, and the build picks it up.

    Assembled at build time
    Discovery happens once, not on every boot.
    Most agent frameworks wire tools, skills, routes and schedules together at request time. BxAgents does the work in bxAgents build and ships an ordinary app.
    
  
    
    
    Discover
    Walk the convention folders that exist and have content.
    
    
    Validate
    Reject bad config before anything runs.
    
    
    Manifest
    Record what was found in manifest.json.
    
    
    Generate
    Write config, handlers, router and scheduler.
    
    
    Run
    Boot .build/app like any ColdBox app, or ship a .bxa.
    
  
    
  
    
    
    Wired at request time
    Convention scanning and file walking on every boot, and build work deferred into the request path.
    
    
    Wired at build time
    No scanning at startup. Starting the agent is booting a plain ColdBox application.
